Kubernetes Homelab & Observability Platform

Migrated my single-node Docker platform to a highly available, three-node k3s cluster, improving fault tolerance and cutting service downtime by 60% compared with the previous deployment.

Infrastructure - The personal site and its Kubernetes-aware status API run as replicated workloads. Redundant Cloudflare Tunnel connectors provide ingress without exposing inbound ports on my home network.

Automation - ArgoCD continuously reconciles the cluster through a GitOps workflow. GitHub Actions builds multi-architecture container images, publishes immutable tags to GHCR, and updates the infrastructure repository to trigger deployments.

Observability - Prometheus collects metrics, Grafana provides dashboards, and Promtail ships Kubernetes logs to Loki. Blackbox Exporter, Uptime Kuma, and Alertmanager monitor public services and send failure notifications to Discord.

Next step - I plan to build an AWS serverless reliability control plane that decouples observability from the cluster nodes themselves, keeping health checks and alerting available even when the homelab is degraded or offline.
